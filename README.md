# 识己 · 经历与状态信息表

响应式静态H5，用于收集用户主动提供的现实经验，帮助“识己｜自我认知与人生节奏报告”校准生活场景和关注重点。

正式入口：https://yukinliu.github.io/shiji-reality-calibration/

当前问卷版本为 Reality Calibration v2.3：7 道核心题（第 1 题内含动态追问）和 1 道选填深度题。

- 不调用GPT或其他外部接口；
- 不需要注册或登录；
- 回答仅保存在填写者当前浏览器；
- 完成后由填写者主动导出Markdown；
- 不设置服务器端数据库，不自动收集用户回答。

## 文件结构

- `index.html`：页面入口与基础元信息；
- `styles.css`：桌面端与手机端响应式视觉；
- `app.js`：问卷交互、本地保存、动态分支与Markdown导出；
- `assets/hero-paper-path.jpg`：本地首屏主视觉。

所有运行资源均随页面静态托管，不依赖外部字体、脚本、图片、登录系统或生成式AI服务。

## 视觉方向

核心意象为“一页纸在水雾中展开为通向远山的青绿路径”，通过虚与实、近与远的关系表达从现实经验走向自我理解。配色采用纸本米色、石青、青绿、墨色与少量朱砂，不使用宗教符号或表面化传统纹样。
